HR Vacation Documents UA

Автоматичне створення, попередній перегляд та друк заяв на відпустку відповідно до вимог кадрового документообігу України.

🚀 Основні можливості

  • ✅ Автоматичне заповнення ПІБ працівника
  • ✅ Автоматичне визначення компанії
  • ✅ Автоматичне визначення керівника
  • ✅ Автоматичне визначення підрозділу
  • ✅ Вибір дат початку та закінчення відпустки
  • ✅ Автоматичний розрахунок кількості календарних днів
  • ✅ Попередній перегляд PDF перед друком
  • ✅ Завантаження та друк готової заяви
  • ✅ Сучасний інтерфейс Odoo 17

📄 Підтримувані шаблони заяв

  • Щорічна основна відпустка
  • Відпустка без збереження заробітної плати
  • Відпустка за сімейними обставинами
  • Відпустка у зв'язку з вагітністю та пологами
  • Відпустка для догляду за дитиною

⚙️ Як працює модуль?

  1. Відкрити меню HR → Vacation Documents.
  2. Обрати потрібний тип заяви.
  3. Вказати дату початку та завершення відпустки.
  4. Система автоматично заповнить інформацію про працівника.
  5. Натиснути Preview.
  6. Перевірити PDF документ.
  7. Завантажити або надрукувати заяву.

💡 Автоматично заповнюються

  • ПІБ працівника
  • Назва компанії
  • Безпосередній керівник
  • Структурний підрозділ
  • Період відпустки
  • Кількість календарних днів

🇺🇦 Для підприємств України

Усі шаблони документів розроблено відповідно до типових вимог кадрового документообігу України та можуть використовуватись підприємствами будь-якої форми власності.
