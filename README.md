Vacation Request Documents (Ukraine)

Модуль призначений для автоматизації створення заяв на відпустку
відповідно до вимог кадрового документообігу України.

Працівник відкриває майстер створення заяви, обирає тип відпустки,
вказує необхідні дати, після чого система автоматично формує документ,
використовуючи дані з кадрової картки працівника.

Модуль автоматично підставляє:
• ПІБ працівника;
• назву підприємства;
• керівника;
• структурний підрозділ;
• період відпустки;
• кількість календарних днів.

Передбачено:
• попередній перегляд документа у форматі PDF;
• завантаження та друк заяви;
• використання готових шаблонів заяв.

Підтримуються такі типи заяв:
• щорічна основна відпустка;
• відпустка без збереження заробітної плати;
• відпустка за сімейними обставинами;
• відпустка у зв'язку з вагітністю та пологами;
• відпустка для догляду за дитиною.

Модуль розроблений для використання підприємствами України та відповідає
типовим вимогам оформлення кадрових документів.
